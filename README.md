🐦 Flappy Bird for M5StickS3

A simple Flappy Bird-style game made for the M5StickS3 using Arduino.

This project is still a work in progress, so new features and improvements may be added over time!

🚀 Getting Started

Follow these steps to get the game running on your M5StickS3.

1. Download the Arduino File

Download the Arduino project/file included with this project.

2. Put Your M5StickS3 Into Download Mode

Connect your M5StickS3 to your computer using USB and put the device into Download Mode so Arduino can upload the program.

3. Open the Project

Open the downloaded Arduino file/project in the Arduino IDE.

Make sure all required libraries and board settings are installed before uploading.

4. Select the Correct Board and Port

In Arduino IDE, make sure you have:

The correct M5StickS3 board selected.
The correct COM/USB port selected.
All required libraries installed.

If you are unsure how to set these up, use the official M5Stack documentation linked below.

5. Upload the Game

Once everything is configured correctly, click Upload in Arduino IDE.

Wait for the upload to finish.

6. Start Playing! 🎮

Once the upload is complete, turn on your M5StickS3.

The game should start automatically.

🐛 Bugs & Issues

If you experience a bug, please don't randomly add or change code to try to fix it.

Instead:

Check that your board and port are configured correctly.
Make sure all required libraries are installed.
Check the Arduino error message.
Let me know what went wrong.
Include the error message if possible so we can properly troubleshoot it.

This makes it much easier to find the actual problem and prevent new bugs from being introduced.
